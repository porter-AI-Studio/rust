第 3 章 · Part 1：認識 Rust

基礎語法速成：從範例開始

用最少的文字、最多的範例，建立讀得懂後續章節的語法基礎。

這一章的範例以官方《The Rust Programming Language》為主，編譯器錯誤訊息也取自該書；變數與遮蔽（shadowing）的範例取自 Medium 上的〈Mastering Rust: The Ultimate Example-Driven Tutorial〉，屬第三方教學。你可以把每個範例貼進上一章建立的專案的 src/main.rs 執行。

變數：預設不可變，可用 mut 與遮蔽

Rust 的變數預設不可變，要修改就得加 mut。另一個特色是遮蔽：用 let 重新宣告同名變數，新的變數會蓋掉舊的，且型別可以不同。下面是 Mastering Rust 的範例（節錄）。

遮蔽（取自 Mastering Rust 教學）
let x = 5;
let x = x + 1; // Shadows the previous `x`
let x = x * 2; // Shadows the new `x`
println!("The value of x is: {}", x); // Output: The value of x is: 12

資料型別：靜態型別，大多能推斷

Rust 是靜態型別語言，編譯期必須知道所有變數的型別。編譯器通常能推斷，但當有多種可能（例如 parse）時就得標註型別。官方範例：

型別標註（Rust Book，Data Types）
let guess: u32 = "42".parse().expect("Not a number!");

Rust Book 把型別分成純量（scalar）與複合（compound）：純量有整數、浮點數、布林與字元；複合型別有元組（tuple）與陣列（array）。整數有 i8 到 u64 等有號與無號長度。整數溢位在 debug 模式會 panic，用 --release 編譯則不檢查，而是環繞（wrapping）：u8 的 256 變成 0。官方明確說：依賴溢位環繞的行為是一種錯誤。元組與陣列的寫法如下。

元組解構與陣列（Rust Book，Data Types）（1／2）
fn main() {
    let tup = (500, 6.4, 1);

    let (x, y, z) = tup;

    println!("The value of y is: {y}");
}
元組解構與陣列（Rust Book，Data Types）（2／2，另一個獨立範例，各自放進自己的 main.rs）
fn main() {
    let a: [i32; 5] = [1, 2, 3, 4, 5];
    let a = [3; 5];
}

陣列存取越界時，Rust 不會讀到不該讀的記憶體，而是在執行期 panic。Rust Book 的互動範例輸入索引 10，得到下面的輸出：

越界存取的 panic 訊息（Rust Book，Data Types）
thread 'main' panicked at src/main.rs:19:19:
index out of bounds: the len is 5 but the index is 10
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace

控制流：if 是運算式，loop 能回傳值

if 的條件必須是 bool，Rust 不會自動把整數當布林。更特別的是 if 是運算式，可以放在 let 右邊，不過各個分支的型別必須一致，否則編譯失敗。

if 作為運算式（Rust Book，Listing 3-2）
fn main() {
    let condition = true;
    let number = if condition { 5 } else { 6 };

    println!("The value of number is: {number}");
}
分支型別不一致的編譯錯誤（Rust Book，節錄）
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:4:44
  |
4 |     let number = if condition { 5 } else { "six" };
  |                                 -          ^^^^^ expected integer, found `&str`

迴圈有三種：loop、while 與 for。loop 可用 break 帶出值，巢狀迴圈則可用標籤指定要跳出哪一層。遍歷集合時，官方說 for 比自己維護索引的 while 更安全簡潔，消除了索引超出範圍或漏掉元素的錯誤，因此是 Rust 最常用的迴圈。

loop 回傳值與倒數 for（Rust Book，Control Flow）（1／2）
fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("The result is {result}");
}
loop 回傳值與倒數 for（Rust Book，Control Flow）（2／2，另一個獨立範例，各自放進自己的 main.rs）
fn main() {
    for number in (1..4).rev() {
        println!("{number}!");
    }
    println!("LIFTOFF!!!");
}

struct 與 enum：用型別描述資料

struct 把相關欄位組成自訂型別。整份實例若要修改欄位，整個實例都必須是 mut，Rust 不允許只標某幾個欄位可變。官方示範了欄位簡寫與更新語法 ..user1，後者把其餘欄位從既有實例搬移過來；若搬移了 String 欄位，user1 就不能再整體使用，這個細節會在所有權章節再解釋。

struct 定義與更新語法（Rust Book，Listing 5-1 與 5-7）
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64,
}

fn main() {
    let user1 = User {
        email: String::from("someone@example.com"),
        username: String::from("someusername123"),
        active: true,
        sign_in_count: 1,
    };

    let user2 = User {
        email: String::from("another@example.com"),
        ..user1
    };
}

除了有名稱欄位的 struct，還有元組 struct（如 struct Color(i32, i32, i32);，欄位只有位置沒有名稱，不同名稱即為不同型別），以及沒有任何欄位的類單元 struct（如 struct AlwaysEqual;）。另外，官方還示範了把欄位型別寫成 &str 會得到 E0106「missing lifetime specifier」：struct 要持有借來的資料，就必須宣告生命週期；初學階段直接用 String 讓 struct 擁有資料即可，生命週期留到第 7 章。

enum 的每個變體（variant）可以帶不同型別與數量的資料，這比用 struct 另外存「種類」再配資料更精簡。標準函式庫的 Option<T> 就是 enum：Rust 沒有 null，而是用它表達「有值或沒有值」，值不是 Some(T) 就是 None，編譯器會強迫你處理沒有值的情況。例如 i8 不能直接和 Option<i8> 相加，編譯器回報「cannot add Option<i8> to i8」。

enum 的變體可攜帶資料與 Option（Rust Book，Listing 6-2 與 Option 一節）
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}

fn main() {
    let some_number = Some(5);
    let some_char = Some('e');

    let absent_number: Option<i32> = None;
}

match：窮盡性檢查

match 把值依序與模式比對，執行第一個符合的分支，並能把變體裡的值綁定到變數。最關鍵的是窮盡性（exhaustive）：所有可能都必須有分支，否則編譯失敗，所以不可能忘記處理 None。官方範例如下；若 Option<i32> 的 match 少寫了 None 分支，就會得到 E0004 錯誤。

match 搭配 enum 與 Option（Rust Book，Listing 6-4 與其後的 match 範例）
#[derive(Debug)]
enum UsState {
    Alabama,
    Alaska,
    // --snip--
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter(UsState),
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter(state) => {
            println!("State quarter from {state:?}!");
            25
        }
    }
}

fn main() {
    value_in_cents(Coin::Quarter(UsState::Alaska));
}
漏掉 None 時的編譯錯誤（Rust Book，節錄）
error[E0004]: non-exhaustive patterns: `None` not covered
 --> src/main.rs:3:15
  |
3 |         match x {
  |               ^ pattern `None` not covered

不想逐一列舉時，可用 other 綁定剩餘值，或用 _ 表示不在乎的萬用分支，_ => () 則是什麼都不做。

Vec 與 String：兩個最常用的集合

Vec<T> 是可成長的陣列，用 vec![] 巨集建立，push 新增元素。讀取元素有兩種方式：&v[2] 越界會 panic，v.get(2) 則回傳 Option<&i32>，越界時是 None，由你決定如何處理。更重要的是借用規則：持有元素參考的同時，不能對 Vec 做會改變它的操作。

Vec 的兩種讀取方式（Rust Book，Listing 8-4）
fn main() {
    let v = vec![1, 2, 3, 4, 5];

    let third: &i32 = &v[2];
    println!("The third element is {third}");

    let third: Option<&i32> = v.get(2);
    match third {
        Some(third) => println!("The third element is {third}"),
        None => println!("There is no third element."),
    }
}
持有參考時修改 Vec（Rust Book，Listing 8-6，無法編譯）
fn main() {
    let mut v = vec![1, 2, 3, 4, 5];

    let first = &v[0];

    v.push(6);

    println!("The first element is: {first}");
}

這段無法編譯，編譯器回報 E0502：v 同時被不可變借用與可變借用。原因是 push 可能需要重新配置記憶體，舊的參考就會指向已釋放的位置，編譯器在編譯期就擋下。這就是第 6 章「借用」要詳細討論的規則。

字串則有兩個層次：核心語言只有字串切片 str（通常以 &str 出現，字面值即是），而 String 是標準函式庫提供、可成長、可變、擁有資料的 UTF-8 字串。串接可用 + 或 format!，format! 不會取得任何參數的所有權。

串接字串的兩種方式（Rust Book，Strings 一節）（1／2）
fn main() {
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
}
串接字串的兩種方式（Rust Book，Strings 一節）（2／2，另一個獨立範例，各自放進自己的 main.rs）
fn main() {
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = format!("{s1}-{s2}-{s3}");
}

另外，Rust 不允許用整數索引字串，如 s1[0]，因為 UTF-8 是變長編碼，位元組、Unicode 純量值與字素群是三個不同層次；切片則要落在字元邊界上，否則執行期 panic，官方範例 &hello[0..4] 對西里爾字母「Здравствуйте」的切片就是照這個規則算位元組。要逐字元處理請用 .chars()，要逐位元組請用 .bytes()。
